## Digital Life & Well-being: Stress Level Prediction
This project analyzes the impact of digital habits (screen time and sleep quality) on stress levels using a Multiple Linear Regression model.



## Interactive 3D Graph Note
Note: GitHub does not render interactive Plotly charts directly. To view, rotate, and interact with the full 3D regression model, please visit my Kaggle Notebook(https://www.kaggle.com/code/elifcyhn/digital-life-well-being-predicting-stress-level).



## Technologies Used
* **Python(Pandas, NumPy)**
* **Visualizations:** Matplotlib, Seaborn, Plotly (3D)
* **Machine Learning:** Scikit-Learn(Linear Regression)


## How to Run
Activate your environment and install dependencies:
pip install pandas matplotlib seaborn plotly scikit-learn nbformat
